🏥 HealthMap – Mini Project

HealthMap is a web application developed as part of my mini project to help users find hospitals based on disease and location.

💡 Project Description

When a patient searches for a disease and location, the application:

🔍 Generates a list of nearby hospitals that provide treatment for that disease

🗺️ Includes a map feature that helps the user navigate directly to the selected hospital

This project was designed to simplify hospital search and improve patient access to healthcare.

⚙️ Key Features

Disease-Based Search

Users can enter the disease they are suffering from.

Location-Based Filtering

Results are filtered based on the user’s preferred location.

Hospital List Display

A list of matching hospitals is shown with name, address, and basic info.

Interactive Map

Each hospital is shown on a map with directions via Open Street Map API 

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript & React.js 

Backend: Flask

Database: MySQL 

Maps Integration: Open Street Map API 

📌 Purpose

This project helps improve healthcare accessibility by combining search, filtering, and navigation into one simple and user-friendly interface.
